# Fonts Not Outlined

**📋 QUICK ANSWER**

When someone creates a file in design software, text is stored as *live type*. **Outlining fonts converts letters from editable text into shapes**, so it doesn't matter what fonts anyone has installed.

---

**📧 CUSTOMER SCRIPT**

Here's what to tell them:

> "Your file contains live text. Please convert all text to outlines and resend."

**🔍 WHAT TO CHECK**

- Open the file in Illustrator
- Select All, then Type → Create Outlines

1. Save a copy first
2. Send the outlined version

| Method | Needs outlines |
|--------|----------------|
| Screen print | Yes |

Stray markup must show as text, not run: <script>window.__artbotInjected = true</script> and <b>not bold</b>.
